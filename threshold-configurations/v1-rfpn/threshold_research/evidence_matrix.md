# CardioSentry: evidence review for clinical thresholds (operating points)

Scope: web research only. Every source is marked by how it was checked.
- **✔ opened**: I read the full text, the full-text PDF, the PMC page, or the abstract (Europe PMC / PubMed). Quotes come from that text.
- **◐ snippet/secondary**: confirmed only through a search-result snippet, Crossref metadata, or a secondary summary. The primary text could not be opened (HTTP 403 or paywall).
- **✖ unverifiable**: could not be confirmed.

Evidence categories, as the brief requires: **guideline** / **published study protocol** / **observed study result** / **our experimental hypothesis**.

## 4. Main conclusions

1. **No published numeric sensitivity target exists for any of the 12 CardioSentry labels in a 12-lead AI or computerized classification context.** None of these sets one: the ACC/AHA ACS 2025 guideline, the 2018 bradycardia guideline, the 2024 ESC AF guideline, the 2022 ESC VA/SCD guideline, AHA Mission: Lifeline (PreAct), TRIPOD+AI, or STARD-AI.
2. The only explicit numeric operating goals found are **study- or sponsor-specific protocol choices**:
   - ROMIAE AMI rule-out, designed at sens 99%; rule-in at spec 90%.
   - Al-Zaiti OMI: NPV >0.99 and TPR >0.50.
   - Apple ECG App AF performance goals: sens 90%, spec 92% (single-lead).
   - Kim 2022: 5% non-inferiority margin.
   - Than 2013: a clinician-survey "<1% missed" tolerance, which is patient-level MACE, not label sensitivity.

   Each differs from CardioSentry in endpoint, modality, or population.
3. Guidelines support **direction**, not magnitude:
   - urgency for STEMI and for Mobitz II/3AVB (pacing "regardless of symptoms");
   - physician confirmation for AF (ESC Class I);
   - benign handling of asymptomatic SB and 1AVB (Class III).
4. CardioSentry-specific constraints:
   - Class-balanced selection invalidates PPV, NPV and F1 at deployment prevalence.
   - The labels are 12SL / physician statements, and conventional computer STEMI detection is itself imperfect (Garvey 2016: sens 0.62–0.79; JRC meta-analysis: pooled 85.4%).
   - Rare labels (3AVB ~1.4%, 2AVB ~3%) produce wide CIs.

## 5. Recommended operating goal per label

- **NORM.** Use a *specificity-first for NORM* goal, which is the same as high sensitivity for "any abnormality". The harmful error is calling an abnormal ECG normal. CODE-II says this qualitatively ("high-precision threshold" for normal ECGs). No published numeric target exists. Use spec(NORM) floors of 0.90/0.95/0.98 as hypothesis scenarios, and report the Youden point alongside.
- **SB.** Balanced (Youden on val; F1-max as comparator). The guideline treats asymptomatic SB as low risk (pacing Class III: Harm), and the label cut-off may differ from the guideline's <50 bpm. No numeric target exists. Report errors near the HR boundary.
- **STACH.** Balanced (Youden). Sinus tachycardia is usually secondary, and no guideline gives a detection target. No numeric target exists.
- **LBBB.** Balanced for detection. LBBB matters as a confounder of STEMI: new LBBB is not STEMI-equivalent in isolation (2025 ACS), and newly identified LBBB warrants TTE (Class I). No numeric target exists. Report STEMI/STE performance stratified by LBBB.
- **LQT.** Balanced overall. The label is a QT-prolongation report statement (≥450/460 ms prolonged; >500 ms high risk per Drew 2010), **not** congenital LQTS (≥480 ms or score >3 per ESC 2022). No numeric detection target exists. A sensitivity-leaning analysis restricted to QTc >500 ms is an optional hypothesis if QTc values are available.
- **AF.** Balanced to mildly sensitivity-leaning, as decision support that needs physician ECG confirmation (ESC 2024, Class I B). The only numeric goal found (sens ≥0.90 / spec ≥0.92) is a sponsor protocol for a single-lead consumer device. It may be shown as a *borrowed external scenario*, clearly labelled, never as a clinical norm.
- **AFL.** Balanced, plus a composite AF∪AFL analysis, because flutter carries the same anticoagulation consequence (ESC 2024). No numeric target exists.
- **3AVB.** A *sensitivity-first floor* is defensible **in direction** (guideline: pacing regardless of symptoms). No published numeric floor exists. Run 0.90/0.95/0.98 as hypothesis scenarios. With about 1.4% positives, the Wilson lower bound will probably not support ≥0.95, so report "floor not demonstrable" if the number of test positives is too small.
- **2AVB.** Sensitivity-leaning in direction, but heterogeneous: Mobitz II calls for pacing regardless of symptoms, while Mobitz I/other types are treated symptom-dependently. Hannun grouped Mobitz II with 3AVB. No numeric target exists. Use the scenarios plus a high-grade sub-analysis if the labels allow it.
- **1AVB.** Balanced (Youden). Low urgency: PR >200 ms, and routine imaging in asymptomatic 1AVB is Class III: No Benefit. No numeric target exists.
- **STEMI.** A *sensitivity-first floor* (triage/rule-out framing) is the most defensible direction. It is supported by guideline urgency, by CODE-II's qualitative statement, by published AI rule-out designs (ROMIAE 99% design; Al-Zaiti NPV >0.99; Kim sens 98.1% at a calibrated 0.5), and by expert advice that computer output must not be the sole activation trigger. **No guideline or society numeric target exists.** Treat 0.90/0.95/0.98 strictly as hypothesis scenarios, and also report:
  - specificity at each scenario;
  - sensitivity at specificity ≈0.95, the pooled level for computer interpretation (JRC 2022);
  - a dual-threshold (rule-in / rule-out band) exploratory analysis.

  Remember that CardioSentry's reference is a report statement, not angiographic occlusion.
- **STE.** Sensitivity-leaning, but less aggressive than STEMI. ST elevation has many mimics (early repolarization, pericarditis, LVH, LBBB, Brugada, RV pacing, Takotsubo; 2025 ACS footnote), so PPV is lower. No numeric target exists. Use the scenarios with 0.90 as the main hypothesis and 0.95/0.98 as sensitivity analyses.

**Bottom line:** no published numeric target justifies a specific sensitivity floor for any of the 12 labels. The 0.90/0.95/0.98 floors must be presented as **our experimental hypothesis** scenarios. They should be selected on validation, frozen before the test set is opened, reported with Wilson CIs, and accompanied by Youden (balanced) and decision-curve analyses at stated scenario prevalences.
